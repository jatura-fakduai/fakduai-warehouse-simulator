    เปิดใช้ Messaging API

    Messaging API คือช่องทางที่ให้ n8n รับและส่งข้อความแทนแอดมิน

    1. เข้า OA Manager ครั้งแรกจะเจอ ข้อตกลงเกี่ยวกับการใช้ข้อมูล อ่านแล้วกด ยอมรับ
    2. หน้าต่าง ยินดีต้อนรับ (1/2) กด ต่อไป แล้วในหน้า (2/2) กด ไปหน้าหลัก
    3. กด ⚙ ตั้งค่า ที่มุมขวาบน
    4. ที่เมนูซ้าย กด Messaging API
    5. สถานะยังเป็น "ไม่ใช้งาน" กด ใช้ Messaging API
    6. หน้าต่าง เลือกโพรไวเดอร์ เลือก สร้างโพรไวเดอร์ แล้วตั้งชื่อ (เช่น ai-logistics-provider) หรือเลือกโพรไวเดอร์เดิมที่มีอยู่ แล้วกด ยอมรับ
    7. หน้าต่าง นโยบายความเป็นส่วนตัวและข้อกำหนดการใช้บริการ ทั้งสองช่องไม่บังคับ ปล่อยว่างได้ แล้วกด ตกลง
    8. หน้าต่างยืนยัน ใช้ Messaging API เช็กชื่อบัญชีกับชื่อโพรไวเดอร์ แล้วกด ตกลง
    9. สถานะเปลี่ยนเป็น กำลังใช้งาน และได้ แชนแนล ID มา
    โพรไวเดอร์เปลี่ยนภายหลังไม่ได้ ในหน้าต่างยืนยันจะเตือนว่าเชื่อมต่อแล้วแก้ไขหรือยกเลิกไม่ได้

    Tool คืออะไร

    Tool คือเครื่องมือที่ AI เลือกเรียกเอง เมื่อคิดว่าต้องใช้ AI รู้ว่าเครื่องมือแต่ละตัวทำอะไร จาก Tool Description

      ToolOperationใช้เมื่อ
      Inventory LookupGet Row(s) แท็บ Inventoryถาม SKU ชื่อสินค้า Stock หรือ Location
      Transaction LookupGet Row(s) แท็บ Transactionsถามประวัติการรับเข้าและเบิกออก
      Create AGV JobAppend แท็บ Transactionsหลังผู้ใช้ยืนยันเท่านั้น (Lab 4)

    สมัคร n8n Cloud ↗
    Self-host · ฟรีไม่จำกัดเวลาCommunity Edition ติดตั้งบนเครื่องหรือเซิร์ฟเวอร์ของตัวเองด้วย Docker ต้องมีโดเมน HTTPS (หรือ Cloudflare Tunnel) ถึงจะรับ Webhook จาก LINE ได้
